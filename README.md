# Neon Grill

Static website for the Digital Citizenship themed restaurant project.

## Structure

```text
neon-grill/
├── index.html
├── styles.css
├── script.js
├── .nojekyll
├── README.md
└── assets/
    └── logo.png
```

## Open locally

Open `index.html` in Chrome, Edge, Firefox, or Safari.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload every file in this folder, including the `assets` folder.
3. Commit the files to the `main` branch.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**.
7. Click **Save**.

Your Neon Grill website will then be published with a GitHub Pages URL.
